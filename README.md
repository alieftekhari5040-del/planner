# برنامه‌ریز صعود

برنامه‌ریز روزانه و ردیاب عادت‌های فارسی، با رابط راست‌به‌چپ، تقویم شمسی و ذخیره‌سازی محلی در مرورگر. این پروژه با React و TypeScript ساخته شده و برای استفاده‌ی شخصی، توسعه‌ی تیمی و یادگیری متن‌باز است.

[![مجوز MIT](https://img.shields.io/badge/license-MIT-green.svg)](./LICENSE)
[![رابط فارسی](https://img.shields.io/badge/UI-فارسی%20و%20راست‌به‌چپ-7c3aed.svg)](#ویژگی‌ها)

> **وضعیت پروژه:** نسخه‌ی اولیه‌ی پایدار برای استفاده‌ی محلی. پیشنهادها و مشارکت‌های سازنده از طریق Issue و Pull Request پذیرفته می‌شوند.

## ویژگی‌ها

- برنامه‌ریزی روزانه برای اولویت‌ها، هدف‌ها، روتین‌ها، برنامه‌ها و آموخته‌های روز
- پشتیبانی از تاریخ و نمایش عددهای فارسی با تقویم جلالی/شمسی
- جابه‌جایی بین روزها و تقویم ماهانه
- ردیاب عادت با ماتریس هفتگی، شمارش پیوستگی و وضعیت هر روز
- داشبورد تحلیل بهره‌وری، روند هفتگی و مقایسه‌ی بخش‌های برنامه
- تایمر تمرکز پومودورو با زمان استراحت کوتاه و بلند
- قالب‌های آماده، برنامه‌ی پیشنهادی و داده‌ی نمونه برای شروع سریع
- ذخیره‌سازی خودکار اطلاعات در `localStorage` بدون نیاز به حساب کاربری یا سرور
- خروجی و بازیابی پشتیبان JSON و چاپ/ذخیره‌ی برنامه به شکل PDF از مرورگر
- طراحی واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- رعایت حالت کاهش حرکت، دسترسی پایه‌ی صفحه‌کلید و متن‌های فارسی در رابط کاربری

## فناوری‌ها

- React 19 و TypeScript
- Vite 8 و Tailwind CSS 4
- Lucide React برای آیکون‌ها
- Oxlint برای بررسی کد
- Vitest برای تست‌های واحد

## شروع سریع

### پیش‌نیازها

- Node.js نسخه‌ی `20.19` یا جدیدتر؛ نسخه‌ی پیشنهادی در `.nvmrc` مشخص شده است.
- npm نسخه‌ی سازگار با Node.js

### نصب و اجرا

```bash
git clone https://github.com/alieftekhari5040-del/planner.git
cd planner
npm ci
npm run dev
```

پس از اجرا، آدرس نمایش‌داده‌شده توسط Vite را در مرورگر باز کنید. برای توقف سرور، `Ctrl+C` را بزنید.

## فرمان‌های توسعه

| فرمان | کاربرد |
| --- | --- |
| `npm run dev` | اجرای سرور توسعه با HMR |
| `npm run build` | بررسی TypeScript و ساخت نسخه‌ی تولید |
| `npm run lint` | اجرای Oxlint |
| `npm test` | اجرای تست‌های واحد یک‌باره |
| `npm run test:watch` | اجرای تست‌ها در حالت پایش |
| `npm run test:types` | بررسی TypeScript فایل‌های تست |
| `npm run security` | بررسی آسیب‌پذیری وابستگی‌ها |
| `npm run check` | اجرای lint، تست، بررسی نوع تست‌ها و build به‌صورت متوالی |
| `npm run preview` | نمایش نسخه‌ی ساخته‌شده‌ی تولید |

پیش از ارسال Pull Request، اجرای `npm run check` الزامی است.

## حریم خصوصی و نگهداری داده

این برنامه در حالت فعلی backend، حساب کاربری، تحلیل‌گر، کوکی یا پایگاه‌داده‌ی بیرونی ندارد. داده‌های برنامه و عادت‌ها فقط در حافظه‌ی محلی همان مرورگر ذخیره می‌شوند؛ بنابراین:

- پاک کردن داده‌های سایت یا تغییر مرورگر می‌تواند اطلاعات را حذف کند.
- برای نگهداری مطمئن، از گزینه‌ی **پشتیبان** در برنامه خروجی JSON بگیرید.
- فایل پشتیبان ممکن است شامل تمام نوشته‌ها و عادت‌های شخصی شما باشد؛ آن را عمومی یا در مخزن Git قرار ندهید.
- در اولین اجرای خالی، چند عادت و تاریخچه‌ی نمونه‌ی محلی برای نمایش ماتریس ساخته می‌شود؛ این داده‌ها قابل ویرایش یا حذف هستند.
- برای انتقال داده به مرورگر دیگر، ابتدا از مرورگر قبلی خروجی بگیرید و سپس فایل JSON را در مرورگر جدید بازیابی کنید.

## انتشار

خروجی `npm run build` در پوشه‌ی `dist/` ساخته می‌شود و می‌تواند روی هر میزبان فایل استاتیک منتشر شود. برای نمونه:

1. فرمان ساخت را اجرا کنید: `npm run build`
2. پوشه‌ی `dist/` را در سرویس‌هایی مانند Netlify، Vercel یا GitHub Pages منتشر کنید.
3. در صورت استفاده از مسیر فرعی، مقدار `base` را در `vite.config.ts` متناسب با مسیر انتشار تنظیم کنید.

در محیط توسعه، Vite روی `0.0.0.0` گوش می‌دهد تا پیش‌نمایش‌های ابری و شبکه‌ی محلی نیز کار کنند.
