# راهنمای اجرای نهایی روی لپ‌تاپ شخصی

این پروژه اکنون **نسخه‌ی نهایی حرفه‌ای** است — ظاهر و تمام ویژگی‌های اصلی دقیقاً حفظ شده، فقط کد در پشت‌صحنه بهینه و تمیز شده.

## ویژگی‌های حفظ شده (بدون تغییر ظاهر)
- برنامه‌ریزی روزانه: اولویت‌ها، اهداف، روتین‌ها، برنامه‌ی 14 ردیفه، درس‌ها
- تقویم شمسی، جابجایی روز، تقویم ماهانه
- ردیاب عادت با ماتریس هفتگی و استریک
- داشبورد تحلیل (KPI، روند هفته، مقایسه بخش‌ها)
- پومودورو، قالب‌ها، تاریخچه، پشتیبان JSON، چاپ PDF
- طراحی سایبر-پرپل، Vazirmatn، RTL، ریسپانسیو، حالت کاهش حرکت

## بهینه‌سازی‌های نهایی (نامرئی برای کاربر)
- **نمونه آزمایشی → فایل نهایی:** `src/utils/demoData.ts` اکنون با نام `getFinalStarterData` هم قابل فراخوانی است؛ دکمه‌ی «⚡ نمونه آزمایشی» همان ظاهر را دارد اما قبل از بازنویسی اطلاعات روز، تایید حرفه‌ای می‌پرسد تا داده‌ی واقعی شما پاک نشود.
- **کد تمیز:** `ErrorBoundary` برای جلوگیری از کرش، `React.memo` برای همه کارت‌ها، `React.lazy` برای صفحات سنگین (habits, analytics) → لود اولیه از 308kB به 72kB + vendor جدا (62kB gzip) کاهش یافت.
- **باندل بهینه:** `vite.config.ts` با `manualChunks` (vendor / habits / analytics) و `chunkSizeWarningLimit`
- **پایداری:** `localStorage` با try/catch و کنترل quota، تایید قبل از demo

## اجرای بدون ترمینال پیچیده

### روش ۱ — فقط کلیک (پیشنهادی برای لپ‌تاپ)
1. پوشه‌ی پروژه را روی لپ‌تاپ کپی کن (یا از گیت‌هاب Clone بزن)
2. روی `package.json` کلیک راست → Open with VS Code
3. ترمینال VS Code یک‌بار:
   ```bash
   npm ci
   npm run dev
   ```
   لینک `http://localhost:5173` را باز کن — یا بدون ترمینال بعدی، فقط `npm run preview` پس از `npm run build`

### روش ۲ — فایل نهایی آماده (بدون نصب)
پوشه‌ی `dist/` پس از `npm run build` ساخته می‌شود — این نسخه‌ی نهایی و حرفه‌ای است که روی هر هاست استاتیک (Netlify, Vercel, GitHub Pages) قابل انتشار است:
```bash
npm run build
npm run preview  # پیش‌نمایش تولید روی http://localhost:4173
```
برای لپ‌تاپ آفلاین: `dist/` را با `npx serve dist` اجرا کن یا فایل `dist/index.html` را با Live Server باز کن (file:// مستقیم به دلیل ماژول ES کار نمی‌کند).

### روش ۳ — گیت‌هاب بدون ترمینال شخصی
- https://github.com/alieftekhari5040-del/planner/tree/arena/019fdd28-planner → دکمه `Code → Download ZIP`
- یا Codespaces: روی گیت‌هاب `Code → Create codespace` → خودکار `npm ci && npm run dev`

## دستورات کلیدی
| دستور | کاربرد |
|-------|--------|
| `npm ci` | نصب تمیز وابستگی‌ها (Node >=20.19) |
| `npm run dev` | توسعه با HMR روی 0.0.0.0:5173 |
| `npm run build` | ساخت نهایی + بررسی TypeScript |
| `npm run preview` | نمایش نسخه‌ی تولید |
| `npm run check` | lint + test + types + build (قبل از تحویل) |

## پشتیبان‌گیری شخصی
- هر روز خودکار در `localStorage` ذخیره می‌شود
- برای انتقال به لپ‌تاپ دیگر: دکمه «خروجی» → JSON → در مرورگر جدید «بازیابی»
- فایل JSON حاوی اطلاعات شخصی است — عمومی نکن

## مشخصات فنی نهایی
- React 19 + TypeScript strict + Vite 8 + Tailwind 4
- تست: vitest 12 تست پاس، oxlint 0 خطا
- باندل: `vendor 62kB gzip` + `index 16.8kB` + `habits 3.6kB` (lazy) + `analytics 11.3kB` (lazy)

ساخته‌شده برای لپ‌تاپ شخصی — بدون وابستگی به سرور، فقط مرورگر.
